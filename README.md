# Вариант №7 — этап 2 (Python)

Это самостоятельный проект только для второго этапа задания: по имени и версии Maven-пакета получить POM и вывести **только его прямые зависимости**. Это не проект с выбором между этапами: запуск всегда выполняет сбор данных этапа 2.

## Реализовано

- Чтение координат пакета, версии и репозитория из `config.ini`.
- Чтение POM из локального Maven-layout или по HTTP(S).
- XML-разбор средствами стандартной библиотеки Python.
- Разрешение простых Maven-свойств `${...}` и версий из локального `dependencyManagement`.
- Вывод координат каждой прямой зависимости, `scope` и `optional`, если он установлен в POM.
- Обработка ошибок конфигурации, отсутствующего POM, HTTP-ошибок и некорректного XML.

Программа не обходит зависимости рекурсивно, не использует Maven или сторонние библиотеки для скачивания данных и не строит изображение графа: это выходит за рамки второго этапа по заданию.

## Запуск

Из корня проекта:

```bash
python main.py
python main.py --config config.ini
python -m unittest discover -s tests -v
```

По умолчанию используется локальный тестовый Maven-репозиторий внутри `tests/fixtures/maven-repository`, поэтому демонстрация не требует интернета. Для подключения к Maven Central:

```bash
python main.py --config config.maven-central.ini
```

Чтобы изменить пакет, отредактируйте `name` и `version` в INI-файле. `name` должен быть в формате `groupId:artifactId`.

Требуется Python 3.10 или новее. Дополнительные зависимости устанавливать не нужно.

## Структура

- `src/` — загрузка конфигурации и чтение POM/прямых зависимостей.
- `tests/` — модульные тесты и локальный тестовый Maven-репозиторий.
- `main.py` — единственная точка запуска этапа 2.
- `config.ini` — офлайн-пример.
- `config.maven-central.ini` — удалённый пример.
