# Вариант №7 — этап 2 (Python)

Это отдельный проект только для второго этапа задания. Программа получает
POM-файл Maven-пакета указанной версии, разбирает его и выводит список
**прямых зависимостей**. Транзитивные зависимости не загружаются, граф
зависимостей не строится.

## Параметры конфигурации

Параметры задаются в INI-файле:

- `[package] name` — координаты пакета в формате `groupId:artifactId`.
- `[package] version` — версия пакета, POM которого нужно прочитать.
- `[repository] location` — путь к локальному Maven-репозиторию или URL
  HTTP(S)-репозитория. Также можно указать путь к одному `.pom`-файлу.
- `[repository] mode` — режим репозитория: `auto`, `local` или `remote`.
- `[visualization] graph_image` — имя файла изображения для последующего
  этапа; на втором этапе изображение не создаётся.

В `config.ini` уже настроен локальный тестовый репозиторий из папки
`tests/fixtures/maven-repository`. Он используется для демонстрации и
проверки программы без подключения к интернету.

## Запуск

Распакуйте архив и откройте папку проекта.

### Windows

Запустите `run.bat` двойным щелчком мыши или из командной строки:

```bat
run.bat
```

Для выбора другого INI-файла:

```bat
run.bat --config config.maven-central.ini
```

### Linux и macOS

Сделайте скрипт исполняемым и запустите его:

```bash
chmod +x run.sh
./run.sh
```

Для выбора другого INI-файла:

```bash
./run.sh --config config.maven-central.ini
```

### Запуск через Python

Из корневой папки проекта можно выполнить те же команды напрямую:

```bash
python main.py
python main.py --config config.ini
```

По умолчанию используется `config.ini`, поэтому для первой демонстрации
дополнительные параметры указывать не нужно.

## Проверка тестов

Запустите из корневой папки проекта:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют чтение конфигурации, получение прямых зависимостей из
локального POM, разрешение Maven-свойств и обработку ошибок.

## Пример результата

Для конфигурации по умолчанию программа выводит примерно следующий результат:

```text
Пакет: com.example:demo-app:1.0.0
Прямые зависимости Maven:
- org.example:demo-core:2.1.0 [scope=compile]
- org.example:demo-utils:1.4.0 [scope=runtime, optional=true]
```

## Обработка ошибок

Если конфигурация некорректна, POM отсутствует, недоступен удалённый
репозиторий или XML содержит ошибку, программа выводит сообщение в `stderr`
и завершается с ненулевым кодом возврата. Код `0` означает успешное
выполнение, `2` — ошибку конфигурации, `1` — ошибку получения или разбора POM.

## Требования

Требуется Python 3.10 или новее. Используются только модули стандартной
библиотеки Python, поэтому устанавливать сторонние пакеты не требуется.
Для обращения к удалённому репозиторию необходимо подключение к интернету.

## Структура проекта

```text
src/       чтение конфигурации и обработка Maven POM
 tests/    модульные тесты и локальный тестовый Maven-репозиторий
main.py    точка входа второго этапа
config.ini локальная конфигурация для запуска без интернета
config.maven-central.ini пример конфигурации удалённого репозитория
run.bat    запуск в Windows
run.sh     запуск в Linux и macOS
```
